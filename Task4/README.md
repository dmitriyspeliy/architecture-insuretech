# Задание 4. Проектирование продажи ОСАГО

В рамках задания доработана контейнерная схема InsureTech для запуска нового продукта — онлайн-оформления ОСАГО.

Для интеграции со страховыми компаниями выделен отдельный сервис `osago-aggregator`. Он отвечает за отправку заявок в страховые компании, polling предложений по заявкам и публикацию полученных результатов в `core-app`.

## Основные решения

`osago-aggregator` имеет собственную БД, так как процесс расчёта ОСАГО длительный и асинхронный. В БД хранится состояние расчёта: `correlationId`, заявки во внешние страховые компании, внешние requestId, статусы обработки, полученные предложения, retry-счётчики и deadline 60 секунд.

Интеграция между `core-app` и `osago-aggregator` реализована через Event Broker. `core-app` публикует событие `OsagoApplicationCreated`, а `osago-aggregator` публикует события `OsagoOfferReceived`, `OsagoQuoteCompleted` и `OsagoQuoteTimedOut`.

Для связи всех сообщений одного расчёта используется `correlationId`. Он позволяет сопоставить заявку клиента, запросы в страховые компании и ответы от них.

Для защиты от повторной обработки используется `idempotency key`. Если событие будет доставлено повторно, `osago-aggregator` не отправит повторную заявку в ту же страховую компанию.

Для отображения предложений пользователю по мере поступления выбран SSE-поток от `core-app` к Web UI. Это позволяет показывать предложение сразу после ответа конкретной страховой компании, не дожидаясь завершения расчёта по всем компаниям.

## Отказоустойчивость

На интеграциях со страховыми компаниями применяются:

- `Timeout` — ограничение ожидания ответа страховой компании.
- `Retry` — повтор временных ошибок.
- `Circuit Breaker` — временное отключение нестабильной страховой компании.
- `Rate Limiter` — ограничение количества запросов к API страховых компаний.

Так как `core-app` и `osago-aggregator` могут работать в нескольких репликах, `osago-aggregator` использует consumer group, БД состояния, `correlationId` и идемпотентность для корректной обработки заявок без дублей.
